# Créditos das imagens

As 194 fotos desta pasta (`*.webp`) e a lista de Produtos de `gerar.go` vêm do
**DummyJSON**, de Muhammad Ovi (Owais), projeto publicado em `github.com/Ovi/DummyJSON`.
Cada foto é o `images[0]` de um Produto, em WebP de 1000 px, como veio, sem
redimensionamento nem conversão. O id do Produto no DummyJSON está no campo `origem`
de `gerar.go`. Nomes e descrições foram traduzidos para o português e tiveram as
marcas retiradas.

O download foi feito uma vez, fora do repositório (Estória 8.1). Em tempo de
execução nada é buscado em rede: as fotos vão embutidas no binário (AD-12).

## A origem das fotos

O DummyJSON não declara de onde vêm as fotos nem sob que licença elas estão. A
licença MIT acima cobre o código do projeto, e este arquivo **não afirma que as
fotos sejam livres**. Algumas trazem a marca do fabricante no próprio objeto.

O uso aqui é acadêmico, numa demonstração sem fim comercial. Este registro não é
parecer jurídico. Quem for reaproveitar as fotos fora deste trabalho precisa
verificar os direitos por conta própria.
